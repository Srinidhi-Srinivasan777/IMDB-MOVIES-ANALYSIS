# PRSQL-01 — IMDB Movies SQL Analysis

 ## 📌 Project Overview

 **PRSQL-01-IMDB Movies** is a MySQL-based data analysis project focused on exploring and querying an IMDB movie database.

 The project demonstrates practical SQL skills by answering a series of business and analytical questions related to movies, directors, popularity, revenue, ratings, and gender distribution among directors.

 The analysis uses the `project_movie_database` database and involves querying two primary tables:

 - `movies` — Contains information about movies, including popularity, revenue, ratings, release dates, and director IDs.
- `directors` — Contains information about directors, including their names and gender.

 The project progresses from basic data retrieval and filtering to more advanced SQL operations such as subqueries, joins, aggregation, grouping, sorting, and limiting results.

 The main objectives of this project are to:

 ## 🗄️ Database Structure

 ### `movies`

 The `movies` table contains movie-level information used throughout the analysis.

 Relevant columns include:

 | Column | Description |
| --- | --- |
| `id` | Unique identifier for each movie |
| `director_id` | ID linking the movie to its director |
| `popularity` | Popularity score of the movie |
| `revenue` | Revenue generated by the movie |
| `vote_average` | Average movie rating |
| `release_date` | Movie release date |

### `directors`

 The `directors` table contains information about movie directors.

 Relevant columns include:

 | Column | Description |
| --- | --- |
| `id` | Unique identifier for each director |
| `name` | Director's name |
| `gender` | Gender identifier |

The relationship between the tables is established through:

```
directors.id
     │
     │
     ▼
movies.director_id
```

 # 🔎 Problem Statements & SQL Solutions

 ## A. Retrieve all movie data

 ### Question

 > Can you get all data about movies?

 ### SQL Query

```
SELECT *
FROM movies;
```

 This query retrieves every column and every record from the `movies` table.

---

 ## B. Retrieve all director data

 ### Question

 > How do you get all data about directors?

 ### SQL Query

```
SELECT *
FROM directors;
```

 This returns all available director records and their associated information.

---

 ## C. Count the number of movies

 ### Question

 > Check how many movies are present in IMDB.

 ### SQL Query

```
SELECT COUNT(id)
FROM movies;
```

 The `COUNT()` aggregate function is used to determine the total number of movie records.

---

 ## D. Find specific directors

 ### Question

 > Find these three directors: James Cameron, Luc Besson, and John Woo.

 ### SQL Query

```
SELECT *
FROM directors
WHERE name IN (
    'James Cameron',
    'Luc Besson',
    'John Woo'
);
```

 The `IN` operator allows multiple values to be matched within a single condition.

---

 ## E. Find directors whose names start with "S"

 ### Question

 > Find all directors with names starting with S.

 ### SQL Query

```
SELECT *
FROM directors
WHERE name LIKE 'S%';
```

 The `%` wildcard represents any sequence of characters following the letter `S`.

---

 ## F. Count female directors

 ### Question

 > Count female directors.

 ### SQL Query

```
SELECT *
FROM directors
WHERE gender = 1;
```

 This query filters directors based on the database's gender classification.

 > **Note:** The value `1` is assumed to represent female directors according to the database schema.

 If the objective is specifically to return the count rather than the records, a more direct query would be:

```
SELECT COUNT(*)
FROM directors
WHERE gender = 1;
```

---

 ## G. Find the 10th female director alphabetically

 ### Question

 > Find the name of the 10th first women director.

 ### SQL Query

```
SELECT *
FROM directors
WHERE gender = 1
ORDER BY name ASC
LIMIT 1 OFFSET 9;
```

 ### How it works

 - `WHERE gender = 1` filters female directors.
- `ORDER BY name ASC` sorts the results alphabetically.
- `OFFSET 9` skips the first nine records.
- `LIMIT 1` returns the tenth record.

 This assumes the intended interpretation is **the 10th female director when sorted alphabetically by name**.

---

 ## H. Find the 3 most popular movies

 ### Question

 > What are the 3 most popular movies?

 ### SQL Query

```
SELECT *
FROM movies
ORDER BY popularity DESC
LIMIT 3;
```

 The movies are sorted from highest to lowest popularity, and only the top three records are returned.

---

 ## I. Find the 3 most bankable movies

 ### Question

 > What are the 3 most bankable movies?

 ### SQL Query

```
SELECT *
FROM movies
ORDER BY revenue DESC
LIMIT 3;
```

 Here, **revenue** is used as the measure of a movie's commercial success.

---

 ## J. Find the highest-rated movie since January 1, 2000

 ### Question

 > What is the most awarded average vote since January 1st, 2000?

 ### SQL Query

```
SELECT *
FROM movies
WHERE release_date >= '2000-01-01'
ORDER BY vote_average DESC
LIMIT 1;
```

 This query:

 1. Filters movies released on or after January 1, 2000.
2. Sorts them by average rating in descending order.
3. Returns the highest-rated movie.

 > **Note:** The wording "most awarded average vote" appears to refer to the movie with the highest `vote_average`.

---

 ## K. Find movies directed by Brenda Chapman

 ### Question

 > Which movie(s) were directed by Brenda Chapman?

 ### SQL Query

```
SELECT *
FROM movies
WHERE director_id = (
    SELECT id
    FROM directors
    WHERE name = 'Brenda Chapman'
);
```

 This query demonstrates the use of a **subquery**.

 The inner query first retrieves Brenda Chapman's director ID. The outer query then uses that ID to find her movies.

---

 ## L. Find the director who made the most movies

 ### Question

 > Which director made the most movies?

 ### SQL Query

```
SELECT
    directors.name,
    COUNT(movies.id) AS movie_count
FROM directors
JOIN movies
    ON directors.id = movies.director_id
GROUP BY directors.id, directors.name
ORDER BY movie_count DESC
LIMIT 1;
```

 ### SQL concepts demonstrated

 - `JOIN`
- `COUNT()`
- `GROUP BY`
- `ORDER BY`
- `LIMIT`
- Column aliasing with `AS`

 The query counts the number of movies associated with each director and returns the director with the highest movie count.

---

 ## M. Find the most bankable director

 ### Question

 > Which director is the most bankable?

 ### SQL Query

```
SELECT
    directors.name,
    SUM(movies.revenue) AS total_revenue
FROM directors
JOIN movies
    ON directors.id = movies.director_id
GROUP BY directors.id, directors.name
ORDER BY total_revenue DESC
LIMIT 1;
```

 This query calculates the total revenue generated by movies for each director.

 The director with the highest cumulative movie revenue is considered the **most bankable director** in this analysis.
